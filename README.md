# udemy-cloning

A responsive **Udemy Clone website** built using **HTML and CSS**. This project recreates the basic look and feel of the Udemy learning platform, including course sections, navigation, course cards, categories, and a user-friendly layout.

## 🚀 Features

* Responsive website layout
* Navigation bar with search functionality design
* Course cards and course categories
* Modern and clean UI
* Styled using pure HTML and CSS
* Udemy-inspired homepage design

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🎯 Purpose

This project was created to practice **HTML structure, CSS styling, layouts, Flexbox, and responsive web design** by recreating the interface of a popular online learning platform.
